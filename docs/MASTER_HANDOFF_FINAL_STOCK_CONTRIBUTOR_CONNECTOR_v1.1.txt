A. TUJUAN

Stock Contributor Connector bukan sekadar aplikasi upload gambar.

Produk ini adalah operational bridge untuk mengelola satu paket kerja Contributor: FILE + METADATA, dari upload sampai siap atau terbukti submitted berdasarkan bukti resmi dari platform.

Canonical Flow

UPLOAD → AI ANALYSIS → METADATA → REVIEW → APPROVE → TRANSFER → PLATFORM METADATA READY → FINAL SUBMIT → REVIEW

Setiap tahap harus memiliki status dan bukti yang jelas.

Transfer file tidak sama dengan submission.

ATURAN MUTLAK

FILE_TRANSFERRED != SUBMITTED

File yang berhasil dikirim melalui FTPS belum berarti file sudah disubmit ke Shutterstock.

"FINAL_SUBMIT_REQUIRED" hanya boleh digunakan jika file dan metadata memang sudah siap dan mekanisme resmi platform memerlukan tindakan final dari user.

Platform UI / Documentation Difference

Batas field UI Shutterstock dapat berbeda dengan batas yang tercantum pada dokumentasi.

Karena itu system tidak boleh hanya mengandalkan angka dokumentasi.

Validator harus mengikuti field submission aktual yang digunakan.

Versi sebelumnya mencatat adanya perbedaan konteks antara batas UI sekitar 150 karakter dan dokumentasi yang dapat mencantumkan batas lebih tinggi. Hal tersebut tetap dianggap sebagai concern adapter dan harus diverifikasi pada workflow aktual.

J. DEFINISI STATUS

FILE_TRANSFERRED

Artinya:

File sudah berhasil ditransfer.

Tidak berarti:

- metadata sudah diterapkan
- submission sudah dilakukan
- review sudah dimulai
- file sudah approved

METADATA_READY

Metadata sudah:

- generated
- validated
- persisted

PLATFORM_METADATA_READY

Metadata sudah benar-benar diterapkan melalui mekanisme resmi platform, atau secara jelas sudah siap untuk official import mechanism.

SUBMITTED

Hanya boleh digunakan jika platform menerima submission tersebut.

PENDING_REVIEW

Hanya boleh digunakan jika platform menunjukkan bahwa submission sedang dalam review.

APPROVED

Hanya boleh digunakan jika platform secara eksplisit menyatakan approved.
